# ICPC HUE Reels — Remotion

Programmatic video editing for **ICPC HUE** social reels, built with [Remotion](https://www.remotion.dev/): TikTok-style animated captions generated from `.srt` subtitle files and synced to the audio track.

## Run locally

```bash
npm install
npm start        # preview in Remotion
npm run build    # renders out/video.mp4
```
